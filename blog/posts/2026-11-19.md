**OH. I MADE MORE TOOLS.**

so I made a phone manager.

because apparently I looked at my android phone and decided I needed my own program for talking to it from linux.

I mean... yea. I did.

it's called Riley's Phone Manager. it's written in rust, and I can use it in the terminal to find my phone, open apps, or show the phone screen on my computer. it uses adb and scrcpy, and it can give apps their own little virtual displays too.

I wanted to be able to open something from my phone on my computer without having to keep poking at the phone itself.

there's stuff for app settings, installs, and syncing icons into my desktop menu too. I put the code out on github so people can use it or help add support for other linux desktops.

urm. I may have gotten carried away with it. lol.

and then I made an ssh manager too.

I have a bunch of computers/servers, and I dont wanna remember every name I saved them under. I know which one has LM Studio. I should be able to say "the computer running LM Studio" and have it find that one.

so I made a ssh manager. you give it little notes and tags about your servers and it helps you find them. it works with normal ssh and file transfers too.

I have now made a program to help me find my other computers so I can use the programs I made for those computers.

lol.

**MOONSTONE HAS BEEN BUSY.**

okay. remember the github polling stuff I was talking about before?

Moonstone's been doing a LOT of work on agents runner. the big change is about how often the runner goes looking through the same github stuff over and over.
